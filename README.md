# Lernseiten

Sammel-Repo für Lernseiten (Hilfen, Kontrolllösungen und Nachschlagematerial zu Lernsituationen und Matheblättern).
Jede Seite ist eine einzelne `index.html` in ihrem Ordner und unter `https://oszbau.github.io/<Pfad>/` erreichbar.

| Bereich | Pfad |
|---|---|
| Grundstufe, Lernfelder | `grs/lf2/ls1/` |
| Grundstufe, Mathematik | `grs/mathe/m3a/` |
| Baugeräteführer, Lernfelder | `bgf/lf06/ls1/` |
| Baugeräteführer, Mathematik | `bgf/mathe/ma05/` |
| FHR, Mathematik | `fhr/mathe/integralrechnung/` |
| zweite Fassung derselben Einheit | `grs/lf2/ls2-buch/` |

- `seiten.json` ist das Register aller Seiten.
- `werkzeug/baue_uebersicht.py` erzeugt daraus die Übersichtsseiten.
- Das Repo ist öffentlich: keine personenbezogenen Daten, kein Lehrermaterial, keine Lösungen zu benoteten Produkten.
